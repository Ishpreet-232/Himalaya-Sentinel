# =============================================================
# SETUP INSTRUCTIONS
# =============================================================
#
# 1. Install dependencies:
#    pip install -r requirements.txt
#
# 2. Get API keys (both free):
#    OpenTopography: https://portal.opentopography.org/requestApiKey
#    Copernicus:     https://dataspace.copernicus.eu → Register → OAuth Client
#
# 3. Set keys in config.py
#
# 4. Run pipeline for Chamoli (verify it matches your manual QGIS output):
#    python pipeline/run_pipeline.py --area chamoli
#
# 5. Run for Rudraprayag:
#    python pipeline/run_pipeline.py --area rudraprayag
#
# 6. Run for any Himachal area:
#    python pipeline/run_pipeline.py --area kullu
#    python pipeline/run_pipeline.py --area shimla
#
# 7. Custom bounding box (any Himalayan area):
#    python pipeline/run_pipeline.py --bbox 31.5 31.9 77.0 77.5 --name my_area
#
